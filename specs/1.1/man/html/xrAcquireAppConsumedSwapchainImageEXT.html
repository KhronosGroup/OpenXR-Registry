xrAcquireAppConsumedSwapchainImageEXT(3) Manual Page

Name

xrAcquireAppConsumedSwapchainImageEXT - Returns an image index in an app-consumed swapchain and associated metadata.

C Specification

The xrAcquireAppConsumedSwapchainImageEXT function is defined as:

// Provided by XR_EXT_app_consumed_swapchain
XrResult xrAcquireAppConsumedSwapchainImageEXT(
    XrAppConsumedSwapchainEXT                   appConsumedSwapchain,
    const XrAppConsumedSwapchainImageAcquireInfoEXT* acquireInfo,
    XrAppConsumedSwapchainImageStateEXT*        image);

Parameters

Parameter Descriptions

  • appConsumedSwapchain is an XrAppConsumedSwapchainEXT handle for the swapchain.

  • acquireInfo is an XrAppConsumedSwapchainImageAcquireInfoEXT containing parameters for populating the image.

  • image is a pointer to an XrAppConsumedSwapchainImageStateEXT structure which is populated with information about the acquired image.

Description

This function retrieves the index of the currently available app-consumed swapchain image that was populated by the runtime. This also ensures the image is ready to be accessed by the application. The application may access the acquired image as well as queue GPU operations using it, until the application next calls xrReleaseAppConsumedSwapchainImageEXT.

Associated extensions define the rate at which the runtime becomes ready to provide new image data. If the runtime is not ready when a call is made, it sets XrAppConsumedSwapchainImageStateEXT::ready to false and the XrAppConsumedSwapchainImageStateEXT::imageIndex to any value that is defined to read. (For example, setting it to 0 is valid here.)

The runtime must set XrAppConsumedSwapchainImageStateEXT::unchanged to XR_TRUE if and only if the latest image that is ready to acquire is the same one that was most recently released, with both image data and metadata unchanged. Otherwise, the runtime must set XrAppConsumedSwapchainImageStateEXT::unchanged to XR_FALSE.

When ready, the XrAppConsumedSwapchainImageStateEXT populated by this function contains the image index into the array enumerated by xrEnumerateAppConsumedSwapchainImagesEXT. Structures on the XrAppConsumedSwapchainImageStateEXT::next chain, specified by associated extensions, are able to return additional metadata needed for interpreting the image, if any.

Unless otherwise specified, the application must not attempt to acquire an image when it already has acquired an image from the same swapchain without releasing it. That is, the application is allowed to hold at most one image from a given app-consumed swapchain. If this is violated, the runtime must return XR_ERROR_LIMIT_REACHED from xrAcquireAppConsumedSwapchainImageEXT.

Unless otherwise specified, this call should not block. Instead, the runtime may return the same image as the last acquire, or report that no image is ready.

Unless otherwise specified, once an acquire call returns XrAppConsumedSwapchainImageStateEXT::ready as true, all future acquire calls for the same swapchain must also return it as true. That is, the application may re-acquire the most recently released image even if there is no new image ready.

See https://registry.khronos.org/OpenXR/specs/1.1/html/xrspec.html#ext_app_consumed_swapchain-queue_access for graphics context accessible by the runtime during this call.

Valid Usage (Implicit)

  • The XR_EXT_app_consumed_swapchain extension must be enabled prior to calling xrAcquireAppConsumedSwapchainImageEXT

  • appConsumedSwapchain must be a valid XrAppConsumedSwapchainEXT handle

  • acquireInfo must be a pointer to a valid XrAppConsumedSwapchainImageAcquireInfoEXT structure

  • image must be a pointer to an XrAppConsumedSwapchainImageStateEXT structure

Return Codes
On success, this command returns

  • XR_SUCCESS

  • XR_SESSION_LOSS_PENDING

On failure, this command returns

  • XR_ERROR_CALL_ORDER_INVALID

  • XR_ERROR_FUNCTION_UNSUPPORTED

  • XR_ERROR_HANDLE_INVALID

  • XR_ERROR_INSTANCE_LOST

  • XR_ERROR_LIMIT_REACHED

  • XR_ERROR_RUNTIME_FAILURE

  • XR_ERROR_SESSION_LOST

  • XR_ERROR_VALIDATION_FAILURE
