XrCameraImageDataRawBufferBD(3) Manual Page

Name

XrCameraImageDataRawBufferBD - Raw CPU buffer image data

C Specification

The XrCameraImageDataRawBufferBD structure is defined as:

// Provided by XR_BD_camera_image
typedef struct XrCameraImageDataRawBufferBD {
    XrStructureType    type;
    void*              next;
    uint32_t           width;
    uint32_t           height;
    uint32_t           stride;
    uint32_t           bytesPerPixel;
    uint32_t           pixelStride;
    uint32_t           bufferSize;
    uint8_t*           buffer;
} XrCameraImageDataRawBufferBD;

Members

Member Descriptions

  • type is the XrStructureType of this structure.

  • next is NULL or a pointer to the next structure in a chain. It may include XrCameraIntrinsicsBD and/or XrCameraExtrinsicsBD to request intrinsics and/or extrinsics for the retrieved image.

  • width is the image width in pixels.

  • height is the image height in pixels.

  • stride is the number of bytes between the start of consecutive rows, where stride must be stride ≥ width × pixelStride.

  • bytesPerPixel is the number of bytes per pixel.

  • pixelStride is the number of bytes between consecutive pixels (for packed formats, this equals bytesPerPixel), where pixelStride must be pixelStride ≥ bytesPerPixel.

  • bufferSize is the total size of the image buffer in bytes, where bufferSize must be bufferSize ≥ stride × height.

  • buffer is a pointer to a runtime allocated buffer that contains the raw image data.

Description

This structure retrieves raw CPU buffer data for images transferred via XR_CAMERA_DATA_TRANSFER_TYPE_RAW_BUFFER_BD. The runtime must guarantee the buffer’s validity until the image is released.

The application must not access the buffer after calling xrReleaseCameraImageBD with this image ID.

Valid Usage (Implicit)

  • The XR_BD_camera_image extension must be enabled prior to using XrCameraImageDataRawBufferBD

  • type must be XR_TYPE_CAMERA_IMAGE_DATA_RAW_BUFFER_BD

  • next must be NULL or a valid pointer to the next structure in a structure chain

  • buffer must be a pointer to an array of bufferSize uint8_t values

  • The bufferSize parameter must be greater than 0
