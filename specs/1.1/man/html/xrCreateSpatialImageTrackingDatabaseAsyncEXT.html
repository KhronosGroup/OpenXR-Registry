xrCreateSpatialImageTrackingDatabaseAsyncEXT(3) Manual Page

Name

xrCreateSpatialImageTrackingDatabaseAsyncEXT - Create a spatial image tracking database handle.

C Specification

The xrCreateSpatialImageTrackingDatabaseAsyncEXT function is defined as:

// Provided by XR_EXT_spatial_image_tracking
XrResult xrCreateSpatialImageTrackingDatabaseAsyncEXT(
    XrSession                                   session,
    const XrSpatialImageTrackingDatabaseCreateInfoEXT* createInfo,
    XrFutureEXT*                                future);

Parameters

Parameter Descriptions

  • session is an XrSession in which the spatial image tracking database will be active.

  • createInfo is the XrSpatialImageTrackingDatabaseCreateInfoEXT used to specify the spatial image tracking database parameters.

  • future is a pointer to an XrFutureEXT.

Description

An application can create an XrSpatialImageTrackingDatabaseEXT handle using the xrCreateSpatialImageTrackingDatabaseAsyncEXT function and configure the sets of input reference images of the image tracking database with createInfo.

The runtime must return XR_ERROR_SPATIAL_IMAGE_FORMAT_UNSUPPORTED_EXT if the XrSpatialReferenceImageEXT::format of any of the input reference images is not enumerated by xrEnumerateSpatialReferenceImageFormatsEXT.

The runtime must return XR_ERROR_SPATIAL_IMAGE_INVALID_EXT if the XrSpatialReferenceImageEXT::planes array of any of the input reference images fails to be evaluated according to the reference image metadata of XrSpatialReferenceImageEXT.

The runtime must return XR_ERROR_SPATIAL_IMAGE_INVALID_EXT if the XrSpatialReferenceImageEXT::planes array of any of the input reference images does not provide exactly as many planes as the XrSpatialReferenceImageEXT::format has color channels.

If a runtime enforces a permission system to control application access to the image tracking capability, then the runtime must return XR_ERROR_PERMISSION_INSUFFICIENT if those permissions have not been granted to this application.

This function starts an asynchronous operation and creates a corresponding XrFutureEXT, usable with xrPollFutureEXT and related functions. The return value of this function only indicates whether the parameters were acceptable to schedule the asynchronous operation. The corresponding completion function is xrCreateSpatialImageTrackingDatabaseCompleteEXT, usable when a future from this function is in the READY state, with outputs populated by that function in the completion structure XrCreateSpatialImageTrackingDatabaseCompletionEXT.

Valid Usage (Implicit)

  • The XR_EXT_spatial_image_tracking extension must be enabled prior to calling xrCreateSpatialImageTrackingDatabaseAsyncEXT

  • session must be a valid XrSession handle

  • createInfo must be a pointer to a valid XrSpatialImageTrackingDatabaseCreateInfoEXT structure

  • future must be a pointer to an XrFutureEXT value

Return Codes
On success, this command returns

  • XR_SUCCESS

  • XR_SESSION_LOSS_PENDING

On failure, this command returns

  • XR_ERROR_FUNCTION_UNSUPPORTED

  • XR_ERROR_HANDLE_INVALID

  • XR_ERROR_INSTANCE_LOST

  • XR_ERROR_LIMIT_REACHED

  • XR_ERROR_OUT_OF_MEMORY

  • XR_ERROR_PERMISSION_INSUFFICIENT

  • XR_ERROR_RUNTIME_FAILURE

  • XR_ERROR_SESSION_LOST

  • XR_ERROR_SPATIAL_IMAGE_FORMAT_UNSUPPORTED_EXT

  • XR_ERROR_SPATIAL_IMAGE_INVALID_EXT

  • XR_ERROR_SPATIAL_IMAGE_SIZE_MISSING_EXT

  • XR_ERROR_VALIDATION_FAILURE
