xrAcquireCameraImageBD(3) Manual Page

Name

xrAcquireCameraImageBD - Acquire the latest captured image

C Specification

The xrAcquireCameraImageBD function is defined as:

// Provided by XR_BD_camera_image
XrResult xrAcquireCameraImageBD(
    XrCameraCaptureSessionBD                    captureSession,
    const XrCameraImageAcquireInfoBD*           acquireInfo,
    XrCameraImageBD*                            image);

Parameters

Parameter Descriptions

  • captureSession is a handle to an XrCameraCaptureSessionBD that must be in capturing state.

  • acquireInfo is an XrCameraImageAcquireInfoBD structure containing acquisition parameters.

  • image is an output parameter for an XrCameraImageBD structure describing the acquired image.

Description

Applications call this function to acquire the latest image from a capturing session.

The runtime must return XR_ERROR_CAMERA_CAPTURE_SESSION_NOT_CAPTURING_BD if xrBeginCameraCaptureBD has not been called successfully.

The runtime may limit the number of concurrently acquired images. Exceeding this limit may prevent acquiring new image updates, in which case the runtime must return XR_ERROR_IMAGE_BUFFER_EXHAUSTED_BD for xrAcquireCameraImageBD calls.

The application should release a successfully acquired image by calling xrReleaseCameraImageBD once it is not needed.

Valid Usage (Implicit)

  • The XR_BD_camera_image extension must be enabled prior to calling xrAcquireCameraImageBD

  • captureSession must be a valid XrCameraCaptureSessionBD handle

  • acquireInfo must be a pointer to a valid XrCameraImageAcquireInfoBD structure

  • image must be a pointer to an XrCameraImageBD structure

Return Codes
On success, this command returns

  • XR_SUCCESS

On failure, this command returns

  • XR_ERROR_CAMERA_CAPTURE_SESSION_NOT_CAPTURING_BD

  • XR_ERROR_CAMERA_OCCUPIED_BD

  • XR_ERROR_CAMERA_UNAVAILABLE_BD

  • XR_ERROR_FEATURE_UNSUPPORTED

  • XR_ERROR_FUNCTION_UNSUPPORTED

  • XR_ERROR_HANDLE_INVALID

  • XR_ERROR_IMAGE_BUFFER_EXHAUSTED_BD

  • XR_ERROR_INSTANCE_LOST

  • XR_ERROR_PERMISSION_INSUFFICIENT

  • XR_ERROR_RUNTIME_FAILURE

  • XR_ERROR_TIME_INVALID

  • XR_ERROR_VALIDATION_FAILURE
