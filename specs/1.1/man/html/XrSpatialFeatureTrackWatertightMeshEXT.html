XrSpatialFeatureTrackWatertightMeshEXT(3) Manual Page

Name

XrSpatialFeatureTrackWatertightMeshEXT - Allows applications to enable watertight mesh tracking

C Specification

The XrSpatialFeatureTrackWatertightMeshEXT structure is defined as:

// Provided by XR_EXT_spatial_mesh_tracking
typedef struct XrSpatialFeatureTrackWatertightMeshEXT {
    XrStructureType    type;
    const void*        next;
    XrBool32           enableWatertightMeshTracking;
} XrSpatialFeatureTrackWatertightMeshEXT;

Members

Member Descriptions

  • type is the XrStructureType of this structure.

  • next is NULL or a pointer to the next structure in a structure chain.

  • enableWatertightMeshTracking indicates if the runtime must compute a watertight mesh for the scanned environment.

Description

Runtimes that support watertight mesh tracking must enumerate XR_SPATIAL_CAPABILITY_FEATURE_TRACK_WATERTIGHT_MESH_EXT in xrEnumerateSpatialCapabilityFeaturesEXT. The XR_SPATIAL_CAPABILITY_FEATURE_TRACK_WATERTIGHT_MESH_EXT feature allows the applications to optionally enable watertight mesh tracking and explicitly opt-into any additional compute that the watertight mesh generation may incur.

If XR_SPATIAL_CAPABILITY_FEATURE_TRACK_WATERTIGHT_MESH_EXT is enumerated by xrEnumerateSpatialCapabilityFeaturesEXT for a certain capability, the application can chain XrSpatialFeatureTrackWatertightMeshEXT to the corresponding configuration structure of that capability to indicate whether it wants the tracked mesh to be watertight or not. If the application sets enableWatertightMeshTracking to XR_TRUE, the runtime must compute and provide the application with a watertight mesh of the environment. If the application sets enableWatertightMeshTracking to XR_FALSE, the tracked mesh may still be watertight if the runtime only supports watertight mesh tracking, e.g. in cases where the runtime is providing a processed mesh from a prescanned environment.

Valid Usage (Implicit)

  • The XR_EXT_spatial_mesh_tracking extension must be enabled prior to using XrSpatialFeatureTrackWatertightMeshEXT

  • type must be XR_TYPE_SPATIAL_FEATURE_TRACK_WATERTIGHT_MESH_EXT

  • next must be NULL or a valid pointer to the next structure in a structure chain
