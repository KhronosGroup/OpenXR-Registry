XrLightEstimationDataEnvironmentTextureRawBD(3) Manual Page

Name

XrLightEstimationDataEnvironmentTextureRawBD - Raw environment texture image container

C Specification

The XrLightEstimationDataEnvironmentTextureRawBD structure is defined as:

// Provided by XR_BD_spatial_light_estimation
typedef struct XrLightEstimationDataEnvironmentTextureRawBD {
    XrStructureType                      type;
    const void*                          next;
    XrEnvironmentTexturePixelFormatBD    pixelFormat;
    uint32_t                             cubemapFaceBufferSize;
    uint8_t*                             rightCubemapFaceBuffer;
    uint8_t*                             leftCubemapFaceBuffer;
    uint8_t*                             topCubemapFaceBuffer;
    uint8_t*                             bottomCubemapFaceBuffer;
    uint8_t*                             frontCubemapFaceBuffer;
    uint8_t*                             backCubemapFaceBuffer;
} XrLightEstimationDataEnvironmentTextureRawBD;

Members

Member Descriptions

  • type is the XrStructureType of this structure.

  • next is NULL or a pointer to the next structure in a structure chain.

  • pixelFormat is the color format specified by XrEnvironmentTexturePixelFormatBD.

  • cubemapFaceBufferSize is the size of the raw pixel data buffer in bytes for each face.

  • rightCubemapFaceBuffer points to raw pixel data for the +X face. The buffer size must exactly match cubemapFaceBufferSize value.

  • leftCubemapFaceBuffer points to raw pixel data for the -X face. The buffer size must exactly match cubemapFaceBufferSize value.

  • topCubemapFaceBuffer points to raw pixel data for the +Y face. The buffer size must exactly match cubemapFaceBufferSize value.

  • bottomCubemapFaceBuffer points to raw pixel data for the -Y face. The buffer size must exactly match cubemapFaceBufferSize value.

  • frontCubemapFaceBuffer points to raw pixel data for the -Z face. The buffer size must exactly match cubemapFaceBufferSize value.

  • backCubemapFaceBuffer points to raw pixel data for the +Z face. The buffer size must exactly match cubemapFaceBufferSize value.

Description

The XrLightEstimationDataEnvironmentTextureRawBD structure contains raw pixel data for environment textures retrieved from light estimation provider.

When using XrLightEstimationDataEnvironmentTextureRawBD to retrieve environment texture data, the application must

  • Pass valid pointers for all six face pointers (rightCubemapFaceBuffer to backCubemapFaceBuffer).

  • Ensure the allocated buffers have a size of at least cubemapFaceBufferSize bytes per face.

  • Set cubemapFaceBufferSize to the total data size per face, calculated as: [source] faceSize = resolutionWidth × resolutionHeight × bytesPerPixel where resolutionWidth and resolutionHeight are derived from the active XrEnvironmentTextureResolutionBD, and bytesPerPixel is defined by XrEnvironmentTexturePixelFormatBD.

and the runtime must

  • Return XR_ERROR_VALIDATION_FAILURE if cubemapFaceBufferSize does not equal the expected value described above.

  • Write texture data when the XrSpatialEntityComponentDataLightEstimationBD::isValid member returns XR_TRUE.

  • Write texture data according to the layout defined by the active XrEnvironmentTextureResolutionBD and XrEnvironmentTexturePixelFormatBD, and as illustrated in https://registry.khronos.org/OpenXR/specs/1.1/html/xrspec.html#fig-cubemap-buffer-layout.

Figure 1. Cubemap face buffer layout

Each face buffer must use a top-left origin where the local U axis increases to the right and the V axis increases downward, and be packed in row-major order, as illustrated in https://registry.khronos.org/OpenXR/specs/1.1/html/xrspec.html#fig-cubemap-buffer-layout.

The face mapping in this extension is:

  • +Z (Back): backCubemapFaceBuffer

  • +X (Right): rightCubemapFaceBuffer

  • +Y (Top): topCubemapFaceBuffer

  • -Z (Front): frontCubemapFaceBuffer

  • -X (Left): leftCubemapFaceBuffer

  • -Y (Bottom): bottomCubemapFaceBuffer

Valid Usage (Implicit)

  • The XR_BD_spatial_light_estimation extension must be enabled prior to using XrLightEstimationDataEnvironmentTextureRawBD

  • type must be XR_TYPE_LIGHT_ESTIMATION_DATA_ENVIRONMENT_TEXTURE_RAW_BD

  • next must be NULL or a valid pointer to the next structure in a structure chain

  • pixelFormat must be a valid XrEnvironmentTexturePixelFormatBD value

  • rightCubemapFaceBuffer must be a pointer to an array of cubemapFaceBufferSize uint8_t values

  • leftCubemapFaceBuffer must be a pointer to an array of cubemapFaceBufferSize uint8_t values

  • topCubemapFaceBuffer must be a pointer to an array of cubemapFaceBufferSize uint8_t values

  • bottomCubemapFaceBuffer must be a pointer to an array of cubemapFaceBufferSize uint8_t values

  • frontCubemapFaceBuffer must be a pointer to an array of cubemapFaceBufferSize uint8_t values

  • backCubemapFaceBuffer must be a pointer to an array of cubemapFaceBufferSize uint8_t values

  • The cubemapFaceBufferSize parameter must be greater than 0
