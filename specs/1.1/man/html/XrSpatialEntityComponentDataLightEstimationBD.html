XrSpatialEntityComponentDataLightEstimationBD(3) Manual Page

Name

XrSpatialEntityComponentDataLightEstimationBD - Light estimation component data container

C Specification

The XrSpatialEntityComponentDataLightEstimationBD structure contains light estimate state information retrieved from a spatial entity, and is defined as:

// Provided by XR_BD_spatial_light_estimation
typedef struct XrSpatialEntityComponentDataLightEstimationBD {
    XrStructureType    type;
    void*              next;
    XrBool32           isValid;
} XrSpatialEntityComponentDataLightEstimationBD;

Members

Member Descriptions

  • type is the XrStructureType of this structure.

  • next is NULL or a pointer to the next structure in a structure chain, such as XrLightEstimationDataSphericalHarmonicsBD, XrLightEstimationDataEnvironmentTextureRawBD.

  • isValid is an XrBool32 indicating whether the light estimation component data is valid.

Description

The XrSpatialEntityComponentDataLightEstimationBD is an output structure for getting the light estimate data from an entity in the snapshot. This corresponds to an XrSpatialEntityComponentTypeBD value of XR_SPATIAL_ENTITY_COMPONENT_TYPE_LIGHT_ESTIMATION_BD.

An applicable light estimation data structure is defined as:

  • XrLightEstimationDataSphericalHarmonicsBD if XR_LIGHT_ESTIMATION_CREATE_SPHERICAL_HARMONICS_BIT_BD was set in XrSenseDataProviderCreateInfoLightEstimationBD::createFlags when the provider was created.

  • XrLightEstimationDataEnvironmentTextureRawBD if XR_LIGHT_ESTIMATION_CREATE_ENVIRONMENT_TEXTURE_BIT_BD was set in XrSenseDataProviderCreateInfoLightEstimationBD::createFlags when the provider was created.

If the next chain of XrSpatialEntityComponentDataLightEstimationBD does not contain any applicable light estimation data structures, the runtime must still populate isValid. The runtime must not return XR_ERROR_VALIDATION_FAILURE solely because no applicable light estimation data structures are chained.

Note
Note

To access spatial location information associated with light estimate data, applications follow the process of getting XrSpatialEntityComponentDataLocationBD from XrSpatialEntityIdBD defined in XR_BD_spatial_sensing.
Valid Usage (Implicit)

  • The XR_BD_spatial_light_estimation extension must be enabled prior to using XrSpatialEntityComponentDataLightEstimationBD

  • type must be XR_TYPE_SPATIAL_ENTITY_COMPONENT_DATA_LIGHT_ESTIMATION_BD

  • next must be NULL or a valid pointer to the next structure in a structure chain. See also: XrLightEstimationDataEnvironmentTextureRawBD, XrLightEstimationDataSphericalHarmonicsBD
