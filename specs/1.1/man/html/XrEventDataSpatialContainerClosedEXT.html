XrEventDataSpatialContainerClosedEXT(3) Manual Page

Name

XrEventDataSpatialContainerClosedEXT - Event notifying a spatial container is no longer usable

C Specification

When a spatial container is no longer usable, runtimes must queue an XrEventDataSpatialContainerClosedEXT event.

// Provided by XR_EXT_spatial_container
typedef struct XrEventDataSpatialContainerClosedEXT {
    XrStructureType          type;
    const void*              next;
    XrSpatialContainerEXT    spatialContainer;
} XrEventDataSpatialContainerClosedEXT;

Members

Member Description

  • type is the XrStructureType of this structure.

  • next is NULL or a pointer to the next structure in a structure chain. No such structures are defined in core OpenXR or this extension.

  • spatialContainer is the XrSpatialContainerEXT that this event is for.

Description

Receiving the XrEventDataSpatialContainerClosedEXT event indicates that the runtime is no longer able to display a spatial container, for example due to the user clicking a "close" button or the session entering the XR_SESSION_STATE_LOSS_PENDING state.

After receiving the XrEventDataSpatialContainerClosedEXT event, an app should stop using that spatial container, tear down any associated state such as a render loop, and destroy the container. Runtimes must return XR_ERROR_SPATIAL_CONTAINER_CLOSED_EXT from all functions operating on that container other than xrDestroySpatialContainerEXT.

If a spatial container is visible when the runtime queues a close event, runtimes must first change the container to not visible and queue an XrEventDataSpatialContainerVisibleChangedEXT event.

Valid Usage (Implicit)

  • The XR_EXT_spatial_container extension must be enabled prior to using XrEventDataSpatialContainerClosedEXT

  • type must be XR_TYPE_EVENT_DATA_SPATIAL_CONTAINER_CLOSED_EXT

  • next must be NULL or a valid pointer to the next structure in a structure chain
