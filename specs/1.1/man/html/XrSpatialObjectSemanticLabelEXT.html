XrSpatialObjectSemanticLabelEXT(3) Manual Page

Name

XrSpatialObjectSemanticLabelEXT - Object semantic label

C Specification

// Provided by XR_EXT_spatial_object_tracking
typedef enum XrSpatialObjectSemanticLabelEXT {
    XR_SPATIAL_OBJECT_SEMANTIC_LABEL_UNCATEGORIZED_EXT = 1,
    XR_SPATIAL_OBJECT_SEMANTIC_LABEL_SOFA_EXT = 2,
    XR_SPATIAL_OBJECT_SEMANTIC_LABEL_BED_EXT = 3,
    XR_SPATIAL_OBJECT_SEMANTIC_LABEL_CHAIR_EXT = 4,
    XR_SPATIAL_OBJECT_SEMANTIC_LABEL_TABLE_EXT = 5,
    XR_SPATIAL_OBJECT_SEMANTIC_LABEL_LAMP_EXT = 6,
    XR_SPATIAL_OBJECT_SEMANTIC_LABEL_PLANT_EXT = 7,
    XR_SPATIAL_OBJECT_SEMANTIC_LABEL_DISPLAY_SCREEN_EXT = 8,
    XR_SPATIAL_OBJECT_SEMANTIC_LABEL_WALL_ART_EXT = 9,
    XR_SPATIAL_OBJECT_SEMANTIC_LABEL_CABINET_EXT = 10,
    XR_SPATIAL_OBJECT_SEMANTIC_LABEL_MAX_ENUM_EXT = 0x7FFFFFFF
} XrSpatialObjectSemanticLabelEXT;

Description

The XrSpatialObjectSemanticLabelEXT enumeration describes a set of semantic labels for objects.

For entities with the XR_SPATIAL_OBJECT_SEMANTIC_LABEL_DISPLAY_SCREEN_EXT label, the +Z axis of the https://registry.khronos.org/OpenXR/specs/1.1/html/xrspec.html#ext_spatial_entity_bounded3D_component component must roughly match the surface normal of the screen.

For entities with the XR_SPATIAL_OBJECT_SEMANTIC_LABEL_WALL_ART_EXT label, the +Z axis of the https://registry.khronos.org/OpenXR/specs/1.1/html/xrspec.html#ext_spatial_entity_bounded3D_component component must match the surface normal of the wall the art is discovered on.

For entities with the XR_SPATIAL_OBJECT_SEMANTIC_LABEL_TABLE_EXT label, the +Z axis of the https://registry.khronos.org/OpenXR/specs/1.1/html/xrspec.html#ext_spatial_entity_bounded3D_component component must match the surface normal of the table.

For all the other labels in XrSpatialObjectSemanticLabelEXT, the application must not make any assumptions about how the XrBoxf::center::orientation provided by the https://registry.khronos.org/OpenXR/specs/1.1/html/xrspec.html#ext_spatial_entity_bounded3D_component component on the entity aligns with the physical attributes of that object.

The enumeration values have the following meanings:

Enum Description

XR_SPATIAL_OBJECT_SEMANTIC_LABEL_UNCATEGORIZED_EXT

The runtime was unable to classify this entity.

XR_SPATIAL_OBJECT_SEMANTIC_LABEL_SOFA_EXT

The entity is a sofa.

XR_SPATIAL_OBJECT_SEMANTIC_LABEL_BED_EXT

The entity is a bed.

XR_SPATIAL_OBJECT_SEMANTIC_LABEL_CHAIR_EXT

The entity is a chair.

XR_SPATIAL_OBJECT_SEMANTIC_LABEL_TABLE_EXT

The entity is a table.

XR_SPATIAL_OBJECT_SEMANTIC_LABEL_LAMP_EXT

The entity is a lamp.

XR_SPATIAL_OBJECT_SEMANTIC_LABEL_PLANT_EXT

The entity is a plant.

XR_SPATIAL_OBJECT_SEMANTIC_LABEL_DISPLAY_SCREEN_EXT

The entity is a display screen, like a monitor or TV.

XR_SPATIAL_OBJECT_SEMANTIC_LABEL_WALL_ART_EXT

The entity is a wall art.

XR_SPATIAL_OBJECT_SEMANTIC_LABEL_CABINET_EXT

The entity is a cabinet.
