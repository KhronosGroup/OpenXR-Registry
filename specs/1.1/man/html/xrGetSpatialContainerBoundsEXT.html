xrGetSpatialContainerBoundsEXT(3) Manual Page

Name

xrGetSpatialContainerBoundsEXT - Get the current bounds of a spatial container

C Specification

The xrGetSpatialContainerBoundsEXT function queries the current bounds of a spatial container.

// Provided by XR_EXT_spatial_container
XrResult xrGetSpatialContainerBoundsEXT(
    XrSpatialContainerEXT                       spatialContainer,
    const XrSpatialContainerBoundsGetInfoEXT*   getInfo,
    XrSpatialContainerBoundsEXT*                bounds);

Parameters

Parameter Descriptions

  • spatialContainer is the XrSpatialContainerEXT to query.

  • getInfo is the XrSpatialContainerBoundsGetInfoEXT with the information used to get the state of the spatial container.

  • bounds is a pointer to the XrSpatialContainerBoundsEXT in which the bounds is returned.

Description

While a spatial container is bounded it must not have infinite bounds, while a spatial container is immersive it must have infinite bounds.

Runtimes may change a spatial container’s bounds to any positive finite value at any time while the spatial container is bounded. Changes to a spatial container’s bounds is communicated via XrEventDataSpatialContainerBoundsChangedEXT.

With this extension, an app cannot request changes to bounds other than changing between bounded and immersive with xrRequestSpatialContainerBoundsModeEXT. Other extensions might provide such a way in the future.

Valid Usage (Implicit)

  • The XR_EXT_spatial_container extension must be enabled prior to calling xrGetSpatialContainerBoundsEXT

  • spatialContainer must be a valid XrSpatialContainerEXT handle

  • If getInfo is not NULL, getInfo must be a pointer to a valid XrSpatialContainerBoundsGetInfoEXT structure

  • bounds must be a pointer to an XrSpatialContainerBoundsEXT structure

Return Codes
On success, this command returns

  • XR_SUCCESS

  • XR_SESSION_LOSS_PENDING

On failure, this command returns

  • XR_ERROR_FUNCTION_UNSUPPORTED

  • XR_ERROR_HANDLE_INVALID

  • XR_ERROR_INSTANCE_LOST

  • XR_ERROR_RUNTIME_FAILURE

  • XR_ERROR_SESSION_LOST

  • XR_ERROR_SPATIAL_CONTAINER_CLOSED_EXT

  • XR_ERROR_VALIDATION_FAILURE
