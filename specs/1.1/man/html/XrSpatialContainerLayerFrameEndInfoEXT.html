XrSpatialContainerLayerFrameEndInfoEXT(3) Manual Page

Name

XrSpatialContainerLayerFrameEndInfoEXT - Enable spatial container rendering for a frame

C Specification

In order to render spatial containers, the app must supply a list of layers associated with their respective spatial containers to xrEndFrame. This is accomplished via the XrSpatialContainerLayerFrameEndInfoEXT structure.

// Provided by XR_EXT_spatial_container_self_rendering
typedef struct XrSpatialContainerLayerFrameEndInfoEXT {
    XrStructureType                      type;
    const void*                          next;
    uint32_t                             containerLayerCount;
    const XrSpatialContainerLayerEXT*    containerLayers;
} XrSpatialContainerLayerFrameEndInfoEXT;

Members

Member Description

  • type is the XrStructureType of this structure.

  • next is NULL or a pointer to the next structure in a structure chain.

  • containerLayerCount is the count of elements in the containerLayers array.

  • containerLayers is a pointer to an array of XrSpatialContainerLayerEXT structures.

Description

The containerLayers array contains an XrSpatialContainerLayerEXT for each spatial container in the active render set (the containers managed per-session by xrBeginSpatialContainerRenderingEXT and xrEndSpatialContainerRenderingEXT). Each XrSpatialContainerLayerEXT contains a list of XrCompositionLayerBaseHeader pointers associated with the given spatial container. Runtimes may composite containers in any order they choose, independent of the order of the containerLayers. For example, runtimes may composite containers based on their depth relative to the user, have a spatial container act as a background layer, or 'pin' a spatial container such that it is always on top regardless of its depth. Runtimes may composite layers using different strategies for spatial containers in bounded or immersive modes. For example, runtimes may precomposite each bounded spatial container’s composition layers into a single stereo quad layer that is combined with all other containers in a second composition step.

XrFrameEndInfo::displayTime and XrFrameEndInfo::environmentBlendMode will be applied to all spatial containers supplied in XrSpatialContainerLayerFrameEndInfoEXT.

When this structure is passed to xrEndFrame by being chained onto XrFrameEndInfo, the following additional error cases are added based on the active render set:

  • If a spatial container is referenced by more than one element of containerLayers, runtimes must return XR_ERROR_SPATIAL_CONTAINER_DUPLICATE_EXT.

  • If a spatial container in the active render set is not referenced by an element of containerLayers, runtimes must return XR_ERROR_SPATIAL_CONTAINER_MISSING_EXT.

  • If a spatial container referenced by containerLayers is not a member of the active render set, runtimes must return XR_ERROR_SPATIAL_CONTAINER_NOT_RENDERING_EXT.

Furthermore, if there are any spatial containers in the active render set and this structure is not chained onto XrFrameEndInfo, runtimes must return XR_ERROR_SPATIAL_CONTAINER_MISSING_EXT.

In any of the above error cases, the runtime must not render any content for any spatial container.

Note

If no spatial containers are in the active render set, an app can call xrEndFrame as long as it is not submitting any composition layers.

Note that individual swapchains may be submitted for multiple containers via layers in a valid structure, e.g. A quad layer rendered via a single swapchain submitted to multiple spatial containers. This case is handled uniformly with other rendering: the runtime must render the quad in all such spatial containers.

Valid Usage (Implicit)

  • The XR_EXT_spatial_container_self_rendering extension must be enabled prior to using XrSpatialContainerLayerFrameEndInfoEXT

  • type must be XR_TYPE_SPATIAL_CONTAINER_LAYER_FRAME_END_INFO_EXT

  • next must be NULL or a valid pointer to the next structure in a structure chain

  • containerLayers must be a pointer to an array of containerLayerCount valid XrSpatialContainerLayerEXT structures

  • The containerLayerCount parameter must be greater than 0
