XrCameraCapabilityTypeBD(3) Manual Page

Name

XrCameraCapabilityTypeBD - Type of camera capability

C Specification

The XrCameraCapabilityTypeBD enumeration is defined as:

// Provided by XR_BD_camera_image
typedef enum XrCameraCapabilityTypeBD {
    XR_CAMERA_CAPABILITY_TYPE_IMAGE_RESOLUTION_AND_FRAME_RATE_BD = 1,
    XR_CAMERA_CAPABILITY_TYPE_IMAGE_FORMAT_BD = 2,
    XR_CAMERA_CAPABILITY_TYPE_DATA_TRANSFER_TYPE_BD = 3,
    XR_CAMERA_CAPABILITY_TYPE_CAMERA_MODEL_BD = 4,
    XR_CAMERA_CAPABILITY_TYPE_MAX_ENUM_BD = 0x7FFFFFFF
} XrCameraCapabilityTypeBD;

Description

XrCameraCapabilityTypeBD defines the categories of configurable features supported by a camera (e.g. resolution, frame rate).

For each XrCameraCapabilityTypeBD, two related structures exist:

  1. A child structure of XrCameraSupportedCapabilityBaseHeaderBD: Describes all supported values for the capability.

  2. A child structure of XrCameraCapabilityBaseHeaderBD: Specifies a single value for the capability which can be used for configuration.
