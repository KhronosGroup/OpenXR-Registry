xrCreateAppConsumedSwapchainEXT(3) Manual Page

Name

xrCreateAppConsumedSwapchainEXT - Create an app-consumed swapchain handle.

C Specification

The xrCreateAppConsumedSwapchainEXT function is defined as:

// Provided by XR_EXT_app_consumed_swapchain
XrResult xrCreateAppConsumedSwapchainEXT(
    XrSession                                   session,
    const XrAppConsumedSwapchainCreateInfoEXT*  createInfo,
    XrAppConsumedSwapchainEXT*                  appConsumedSwapchain);

Parameters

Parameter Descriptions

  • session is an XrSession in which the swapchain will be active.

  • createInfo is the XrAppConsumedSwapchainCreateInfoEXT used to configure the swapchain.

  • appConsumedSwapchain is populated with the returned XrAppConsumedSwapchainEXT handle.

Description

This common creation function is customized by use case and associated extensions.

For some associated extensions, the XrAppConsumedSwapchainCreateInfoEXT::next chain of createInfo must contain an additional structure from that extension, in addition to the appropriate value for XrAppConsumedSwapchainCreateInfoEXT::kind.

The number of images in an app-consumed swapchain is at least one.

Unless otherwise specified, if the application destroys a handle used in the additional creation data, after app-consumed swapchain creation but before the corresponding swapchain is destroyed, that swapchain continues to function as if the handle were not destroyed. This mirrors the behavior of actions and action spaces, among other examples in the specification.

Valid Usage (Implicit)

  • The XR_EXT_app_consumed_swapchain extension must be enabled prior to calling xrCreateAppConsumedSwapchainEXT

  • session must be a valid XrSession handle

  • createInfo must be a pointer to a valid XrAppConsumedSwapchainCreateInfoEXT structure

  • appConsumedSwapchain must be a pointer to an XrAppConsumedSwapchainEXT handle

Return Codes
On success, this command returns

  • XR_SUCCESS

  • XR_SESSION_LOSS_PENDING

On failure, this command returns

  • XR_ERROR_FUNCTION_UNSUPPORTED

  • XR_ERROR_HANDLE_INVALID

  • XR_ERROR_INSTANCE_LOST

  • XR_ERROR_LIMIT_REACHED

  • XR_ERROR_OUT_OF_MEMORY

  • XR_ERROR_RUNTIME_FAILURE

  • XR_ERROR_SESSION_LOST

  • XR_ERROR_VALIDATION_FAILURE
