xrEnumerateSwapchainFormats2EXT(3) Manual Page

Name

xrEnumerateSwapchainFormats2EXT - Enumerates swapchain formats

C Specification

The xrEnumerateSwapchainFormats2EXT function is defined as:

// Provided by XR_EXT_enumerate_swapchain_formats2
XrResult xrEnumerateSwapchainFormats2EXT(
    XrSession                                   session,
    XrSwapchainFormatsEnumerateInfoEXT*         enumerateInfo,
    uint32_t                                    formatCapacityInput,
    uint32_t*                                   formatCountOutput,
    int64_t*                                    formats);

Parameters

Parameter Descriptions

  • session is the session that enumerates the supported formats.

  • enumerateInfo is the input parameters to the function.

  • formatCapacityInput is the capacity of the formats, or 0 to retrieve the required capacity.

  • formatCountOutput is a pointer to the count of uint64_t formats written, or a pointer to the required capacity in the case that formatCapacityInput is insufficient.

  • formats is a pointer to an array of int64_t format IDs, but can be NULL if formatCapacityInput is 0. The meanings of the format IDs are specific to the specified graphics API for the session.

  • See the https://registry.khronos.org/OpenXR/specs/1.1/html/xrspec.html#fundamentals-buffer-size-parameters section for a detailed description of retrieving the required formats size.

Description

xrEnumerateSwapchainFormats2EXT enumerates the texture formats supported by the current session. It serves as a compatible but extensible replacement for xrEnumerateSwapchainFormats. For any call to xrEnumerateSwapchainFormats, an equivalent call to xrEnumerateSwapchainFormats2EXT with a default enumerateInfo structure and no chained structures must behave the same. However, some use cases with input parameters require using xrEnumerateSwapchainFormats2EXT and are not convertible to the original function.

The type of formats returned are dependent on the graphics API specified by the graphics binding structure passed to xrCreateSession (unless a structure in the enumerateInfo chain modifies this behavior). For example, if a DirectX graphics API was specified, then the enumerated formats correspond to the DXGI formats, such as DXGI_FORMAT_R8G8B8A8_UNORM_SRGB. Texture formats should be in order from highest to lowest runtime preference. The application should use the highest preference format that it supports for optimal performance and quality.

Runtimes should support R8G8B8A8 and R8G8B8A8 formats with non-linear ("sRGB") encoding if possible.

Runtimes must always return identical buffer contents from this enumeration for a given enumerateInfo structure chain for the lifetime of the session.

Valid Usage (Implicit)

  • The XR_EXT_enumerate_swapchain_formats2 extension must be enabled prior to calling xrEnumerateSwapchainFormats2EXT

  • session must be a valid XrSession handle

  • enumerateInfo must be a pointer to an XrSwapchainFormatsEnumerateInfoEXT structure

  • formatCountOutput must be a pointer to a uint32_t value

  • If formatCapacityInput is not 0, formats must be a pointer to an array of formatCapacityInput int64_t values

Return Codes
On success, this command returns

  • XR_SUCCESS

  • XR_SESSION_LOSS_PENDING

On failure, this command returns

  • XR_ERROR_FUNCTION_UNSUPPORTED

  • XR_ERROR_HANDLE_INVALID

  • XR_ERROR_INSTANCE_LOST

  • XR_ERROR_RUNTIME_FAILURE

  • XR_ERROR_SESSION_LOST

  • XR_ERROR_SIZE_INSUFFICIENT

  • XR_ERROR_VALIDATION_FAILURE
