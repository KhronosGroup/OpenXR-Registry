XrSpatialPlaneSemanticLabel2EXT(3) Manual Page

Name

XrSpatialPlaneSemanticLabel2EXT - Plane semantic label set with door and window

C Specification

// Provided by XR_EXT_spatial_plane_semantic_label2
typedef enum XrSpatialPlaneSemanticLabel2EXT {
    XR_SPATIAL_PLANE_SEMANTIC_LABEL2_UNCATEGORIZED_EXT = 1,
    XR_SPATIAL_PLANE_SEMANTIC_LABEL2_FLOOR_EXT = 2,
    XR_SPATIAL_PLANE_SEMANTIC_LABEL2_WALL_EXT = 3,
    XR_SPATIAL_PLANE_SEMANTIC_LABEL2_CEILING_EXT = 4,
    XR_SPATIAL_PLANE_SEMANTIC_LABEL2_TABLE_EXT = 5,
    XR_SPATIAL_PLANE_SEMANTIC_LABEL2_DOOR_EXT = 6,
    XR_SPATIAL_PLANE_SEMANTIC_LABEL2_WINDOW_EXT = 7,
    XR_SPATIAL_PLANE_SEMANTIC_LABEL_2EXT_MAX_ENUM_EXT = 0x7FFFFFFF
} XrSpatialPlaneSemanticLabel2EXT;

Description

The XrSpatialPlaneSemanticLabel2EXT enumeration describes a set of semantic labels for planes. It is an extension of the XrSpatialPlaneSemanticLabelEXT enumeration and adds the values of door and window to that label set as per https://registry.khronos.org/OpenXR/specs/1.1/html/xrspec.html#ext_spatial_entity_semantic_labels_guidelines

The enumeration values have the following meanings:

Enum Description

XR_SPATIAL_PLANE_SEMANTIC_LABEL2_UNCATEGORIZED_EXT

The runtime was unable to classify this entity.

XR_SPATIAL_PLANE_SEMANTIC_LABEL2_FLOOR_EXT

The entity is a floor.

XR_SPATIAL_PLANE_SEMANTIC_LABEL2_WALL_EXT

The entity is a wall.

XR_SPATIAL_PLANE_SEMANTIC_LABEL2_CEILING_EXT

The entity is a ceiling.

XR_SPATIAL_PLANE_SEMANTIC_LABEL2_TABLE_EXT

The entity is a table.

XR_SPATIAL_PLANE_SEMANTIC_LABEL2_DOOR_EXT

The entity is a door.

XR_SPATIAL_PLANE_SEMANTIC_LABEL2_WINDOW_EXT

The entity is a window.

If an entity that has XR_SPATIAL_COMPONENT_TYPE_PLANE_SEMANTIC_LABEL2_EXT also has XR_SPATIAL_COMPONENT_TYPE_PLANE_SEMANTIC_LABEL_EXT, the semantic meaning of the component data must match. i.e. the XR_SPATIAL_COMPONENT_TYPE_PLANE_SEMANTIC_LABEL_EXT value for that entity must correspond with the XR_SPATIAL_COMPONENT_TYPE_PLANE_SEMANTIC_LABEL2_EXT values according to the following table:
