xrRequestSpatialContainerVisibleEXT(3) Manual Page

Name

xrRequestSpatialContainerVisibleEXT - Request a change to a spatial container

C Specification

Apps request to show or hide a spatial container with xrRequestSpatialContainerVisibleEXT.

// Provided by XR_EXT_spatial_container
XrResult xrRequestSpatialContainerVisibleEXT(
    XrSpatialContainerEXT                       spatialContainer,
    const XrSpatialContainerVisibleRequestInfoEXT* info);

Parameters

Parameter Descriptions

  • spatialContainer is the XrSpatialContainerEXT to request a change for.

  • info is a pointer to an XrSpatialContainerVisibleRequestInfoEXT containing the requested visible state.

Description

Showing or hiding a spatial container is an asynchronous operation.

Apps should request to hide a spatial container before destroying it, enabling runtimes to display a smooth transition. Runtimes should honor requests to hide a spatial container.

A runtime may deny requests to show a spatial container, in which case the runtime must queue an XrEventDataSpatialContainerVisibleRequestDeniedEXT event. For example, some runtimes will deny a request to show a spatial container that the user hid by interacting with a system provided "minimize" button.

Runtimes must not show a spatial container prior to the app requesting to show that spatial container at least once. After the app’s first request to show a spatial container, runtimes may change the visibility that spatial container independent of an app’s requests. This enables the app to control the initial state and contents of a spatial container and enables runtimes to provide system UI like a taskbar that allow a user to choose which spatial containers are visible.

Runtimes must deny requests to show a spatial container in a bounds mode not supported based on XrSystemSpatialContainerPropertiesEXT::supportsBounded and XrSystemSpatialContainerPropertiesEXT::supportsImmersive. This is possible when the default bounds mode, XR_SPATIAL_CONTAINER_BOUNDS_MODE_BOUNDED_EXT, is unsupported for a given system.

Note
Note

On some implementations showing or hiding a spatial container requires communicating with system services and may be deferred until after the user interacts with a system dialog. The asnchyronous design for requesting visibility state changes is intended to allow runtimes the time to complete both of these operations.
Valid Usage (Implicit)

  • The XR_EXT_spatial_container extension must be enabled prior to calling xrRequestSpatialContainerVisibleEXT

  • spatialContainer must be a valid XrSpatialContainerEXT handle

  • info must be a pointer to a valid XrSpatialContainerVisibleRequestInfoEXT structure

Return Codes
On success, this command returns

  • XR_SUCCESS

  • XR_SESSION_LOSS_PENDING

On failure, this command returns

  • XR_ERROR_FUNCTION_UNSUPPORTED

  • XR_ERROR_HANDLE_INVALID

  • XR_ERROR_INSTANCE_LOST

  • XR_ERROR_RUNTIME_FAILURE

  • XR_ERROR_SESSION_LOST

  • XR_ERROR_SPATIAL_CONTAINER_CLOSED_EXT

  • XR_ERROR_VALIDATION_FAILURE
