XrSpatialReferenceImageEXT(3) Manual Page

Name

XrSpatialReferenceImageEXT - Information that defines an input reference image.

C Specification

The XrSpatialReferenceImageEXT structure is defined as:

// Provided by XR_EXT_spatial_image_tracking
typedef struct XrSpatialReferenceImageEXT {
    XrStructureType                           type;
    const void*                               next;
    uint32_t                                  width;
    uint32_t                                  height;
    XrSpatialReferenceImageFormatEXT          format;
    uint32_t                                  planeCount;
    const XrSpatialReferenceImagePlaneEXT*    planes;
} XrSpatialReferenceImageEXT;

Members

Parameter Descriptions

  • type is the XrStructureType of this structure.

  • next is NULL or a pointer to the next structure in a structure chain.

  • width is the pixel width of the reference image.

  • height is the pixel height of the reference image.

  • format is an XrSpatialReferenceImageFormatEXT representing the format of the image.

  • planeCount is the number of elements in the planes array.

  • planes is an array of XrSpatialReferenceImagePlaneEXT structures representing the planes of the image data.

Description

The application can create one or more XrSpatialReferenceImageEXT structures each representing a single input reference image to be passed into the xrCreateSpatialImageTrackingDatabaseAsyncEXT function through XrSpatialImageTrackingDatabaseCreateInfoEXT::spatialReferenceImages when creating an XrSpatialImageTrackingDatabaseEXT handle.

The XrSpatialReferenceImagePlaneEXT::buffer data must be supplied in a left-to-right and top-to-bottom pixel ordering by the application.

The application must provide an XrSpatialReferenceImagePlaneEXT structure in the XrSpatialReferenceImageEXT::planes array for each color channel of the XrSpatialReferenceImageEXT::format.

Valid Usage (Implicit)

  • The XR_EXT_spatial_image_tracking extension must be enabled prior to using XrSpatialReferenceImageEXT

  • type must be XR_TYPE_SPATIAL_REFERENCE_IMAGE_EXT

  • next must be NULL or a valid pointer to the next structure in a structure chain. See also: XrSpatialImageSizeEXT, XrSpatialImageStaticOptimizationEXT

  • format must be a valid XrSpatialReferenceImageFormatEXT value

  • planes must be a pointer to an array of planeCount valid XrSpatialReferenceImagePlaneEXT structures

  • The planeCount parameter must be greater than 0
