XrSpatialContainerLayerEXT(3) Manual Page

Name

XrSpatialContainerLayerEXT - Layers associated with a specific spatial container

C Specification

The XrSpatialContainerLayerEXT structure groups standard composition layers and associates them with a specific spatial container.

// Provided by XR_EXT_spatial_container_self_rendering
typedef struct XrSpatialContainerLayerEXT {
    XrStructureType                               type;
    const void*                                   next;
    XrSpatialContainerEXT                         spatialContainer;
    XrBool32                                      retainPreviousSubmission;
    uint32_t                                      layerCount;
    const XrCompositionLayerBaseHeader* const*    layers;
} XrSpatialContainerLayerEXT;

Members

Member Description

  • type is the XrStructureType of this structure.

  • next is NULL or a pointer to the next structure in a structure chain.

  • spatialContainer is the XrSpatialContainerEXT identifying the target container.

  • retainPreviousSubmission is an XrBool32. If XR_TRUE, the runtime will retain the last submitted frame for this spatial container.

  • layerCount is the number of composition layers in the layers array.

  • layers is a pointer to an array of XrCompositionLayerBaseHeader pointers.

Description

When retainPreviousSubmission is XR_TRUE, the runtime must reuse the composition layers and swapchain image contents as latched during the most recent xrEndFrame call where retainPreviousSubmission was XR_FALSE. Any subsequent modifications to swapchains used by retained layers must not be reflected in the rendered output.

For layers submitted for an individual spatial container (intra-container rendering), the runtime must follow the already specified rules for layer composition ordering. That is to say the layers within containers must be drawn in the same order as they are specified, composed via painter’s algorithm.

Note

"Clearing" a spatial container refers to the removal of all content from a spatial container, resulting in nothing being rendered for that container in the current frame. Runtimes must treat this equivalent to the app submitting transparent black (all bits 0) for every pixel inside the container. "Retaining" a spatial container refers to the runtime continuing to display the most recently submitted set of layers for that container.

For each spatial container the app can specify whether to submit new layers, retain the previous submission, or clear the spatial container:

  • To submit new layers, the app provides a non-zero layerCount and a valid layers pointer.

  • To clear a spatial container, the layerCount for its entry must be 0 and retainPreviousSubmission must be XR_FALSE.

  • To retain the last submitted layers and swapchain images (retaining), the layerCount for its entry must be 0 and retainPreviousSubmission must be XR_TRUE.

This explicit per-container control ensures that the app’s intent is clearly communicated in every frame.

If retainPreviousSubmission is XR_TRUE and layerCount is not 0, the runtime must return XR_ERROR_VALIDATION_FAILURE.

If XrSpatialContainerCompositionLayerViewConfigurationEXT is not chained to an XrCompositionLayerProjection that is part of a spatial container, the runtime must return XR_ERROR_VALIDATION_FAILURE. This structure is only applicable to XrCompositionLayerProjection layers. If it is chained to other layer types (e.g. quad or cylinder layers), the runtime must return XR_ERROR_VALIDATION_FAILURE.

Valid Usage (Implicit)

  • The XR_EXT_spatial_container_self_rendering extension must be enabled prior to using XrSpatialContainerLayerEXT

  • type must be XR_TYPE_SPATIAL_CONTAINER_LAYER_EXT

  • next must be NULL or a valid pointer to the next structure in a structure chain. See also: XrSpatialContainerLayerVolumeClippingEXT

  • spatialContainer must be a valid XrSpatialContainerEXT handle

  • If layerCount is not 0, layers must be a pointer to an array of layerCount valid XrCompositionLayerBaseHeader-based structures. See also: XrCompositionLayerCubeKHR, XrCompositionLayerCylinderKHR, XrCompositionLayerEquirect2KHR, XrCompositionLayerEquirectKHR, XrCompositionLayerPassthroughANDROID, XrCompositionLayerPassthroughFB, XrCompositionLayerPassthroughHTC, XrCompositionLayerProjection, XrCompositionLayerQuad
