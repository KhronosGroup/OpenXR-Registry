XrSpatialKeyboardSemanticLabelEXT(3) Manual Page

Name

XrSpatialKeyboardSemanticLabelEXT - Keyboard semantic label

C Specification

// Provided by XR_EXT_spatial_object_tracking
typedef enum XrSpatialKeyboardSemanticLabelEXT {
    XR_SPATIAL_KEYBOARD_SEMANTIC_LABEL_UNCATEGORIZED_EXT = 1,
    XR_SPATIAL_KEYBOARD_SEMANTIC_LABEL_KEYBOARD_EXT = 2,
    XR_SPATIAL_KEYBOARD_SEMANTIC_LABEL_MAX_ENUM_EXT = 0x7FFFFFFF
} XrSpatialKeyboardSemanticLabelEXT;

Description

The XrSpatialKeyboardSemanticLabelEXT enumeration describes a semantic label for a keyboard.

The extents and orientation of XR_SPATIAL_KEYBOARD_SEMANTIC_LABEL_KEYBOARD_EXT represented by the https://registry.khronos.org/OpenXR/specs/1.1/html/xrspec.html#ext_spatial_entity_bounded3D_component component on the same entity is shown in the following image (with xyz = rgb) originating at the center of the object.

Figure 1. Keyboard orientation.
Enum Description

XR_SPATIAL_KEYBOARD_SEMANTIC_LABEL_UNCATEGORIZED_EXT

The runtime was unable to classify this entity.

XR_SPATIAL_KEYBOARD_SEMANTIC_LABEL_KEYBOARD_EXT

The entity is a keyboard.
