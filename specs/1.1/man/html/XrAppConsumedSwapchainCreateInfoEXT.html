XrAppConsumedSwapchainCreateInfoEXT(3) Manual Page

Name

XrAppConsumedSwapchainCreateInfoEXT - Information to create an app-consumed swapchain handle

C Specification

The XrAppConsumedSwapchainCreateInfoEXT structure is defined as:

// Provided by XR_EXT_app_consumed_swapchain
typedef struct XrAppConsumedSwapchainCreateInfoEXT {
    XrStructureType                  type;
    const void*                      next;
    XrAppConsumedSwapchainKindEXT    kind;
    XrSwapchainUsageFlags            usageFlags;
    int64_t                          format;
} XrAppConsumedSwapchainCreateInfoEXT;

Members

Member Descriptions

  • type is the XrStructureType of this structure.

  • next is NULL or a pointer to the next structure in a structure chain.

  • kind is the specific kind of app-consumed swapchain to create, as specified by the associated derived extension.

  • usageFlags is a bitmask of XrSwapchainUsageFlagBits describing the intended usage of the swapchain’s images. The usage flags define how the corresponding graphics API objects are created. A mismatch may result in swapchain images that do not support the application’s usage. Acceptable values depend on the derived extension.

  • format is a graphics API-specific texture format identifier. For example, if the graphics API specified in xrCreateSession is Vulkan, then this format is a Vulkan format such as VK_FORMAT_R8G8B8A8_SRGB. The format identifies the format in which the application will interpret the texture upon acquire. Valid formats are enumerated as specified by the associated extension providing the swapchain images. The intended pattern is for such extensions to extend the input to xrEnumerateSwapchainFormats2EXT.

Description

The XrAppConsumedSwapchainCreateInfoEXT structure describes the information to create an XrAppConsumedSwapchainEXT handle.

If the value of usageFlags does not match the valid usage requirements of the associated extension, the runtime must return XR_ERROR_VALIDATION_FAILURE.

If the value of format does not match the valid usage requirements of the associated extension, the runtime must return XR_ERROR_VALIDATION_FAILURE.

Some XrAppConsumedSwapchainKindEXT values need additional data at creation time, beyond that provided in this structure. If the associated extension specifies a required additional data structure for the value of kind, the runtime must return XR_ERROR_VALIDATION_FAILURE from xrCreateAppConsumedSwapchainEXT if such a structure is not found on the next chain.

Valid Usage (Implicit)

  • The XR_EXT_app_consumed_swapchain extension must be enabled prior to using XrAppConsumedSwapchainCreateInfoEXT

  • type must be XR_TYPE_APP_CONSUMED_SWAPCHAIN_CREATE_INFO_EXT

  • next must be NULL or a valid pointer to the next structure in a structure chain

  • kind must be a valid XrAppConsumedSwapchainKindEXT value

  • usageFlags must be 0 or a valid combination of XrSwapchainUsageFlagBits values
